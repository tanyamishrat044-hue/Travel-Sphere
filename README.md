
# 🌍 Travel Sphere

A travel website designed to help users explore destinations and plan trips.

## ✨ Features

- Browse popular travel destinations
- View travel information
- Use a trip-planning form
- Navigate between website sections
- Explore a developing, travel-focused UI

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚧 Project Status

Currently in development. I'm improving the styling, layout, and user experience as I continue learning frontend development.

## 🎯 Project Goals

- Build a responsive travel website
- Improve UI and CSS skills
- Practise structuring multi-page websites
- Gradually expand the website's functionality

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
